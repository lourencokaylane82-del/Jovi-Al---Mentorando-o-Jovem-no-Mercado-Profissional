# Jovi-Al---Mentorando-o-Jovem-no-Mercado-Profissional
"Jovi Al é um centro de conhecimento e ecossistema de orientação profissional juvenil, que combina fundamentação científica, análise de mercado e ferramentas práticas de capacitação. O objetivo do caderno é servir como o "cérebro" para guiar jovens brasileiros na transição da escola para o mercado de trabalho.
